# Privacy Policy — WhatsApp to Asana Task Bot

**Last updated: October 29, 2026**

This bot is a personal automation operated by its owner. It turns an authorized WhatsApp task title and photo into a task in one Asana project.

## Information processed

When an authorized sender messages the bot, it processes the sender's WhatsApp phone number, message text or photo caption, WhatsApp message and media identifiers, image type, and the photo itself. A short-lived task title may be held locally for up to five minutes while waiting for its photo. The bot temporarily queues message details and keeps up to 2,000 recent message identifiers to prevent duplicate processing. This state is stored on the operator's computer. Photos are handled in memory and are not saved to that computer.

## How information is used and shared

Message text is used as the task title and notes. The photo is uploaded as an attachment to the task in the configured Asana project, and the bot sends a status reply through WhatsApp. Meta's WhatsApp Business Platform provides message delivery and media retrieval. Asana provides task and attachment storage. These services process information under their own terms and privacy policies. The bot does not sell message content or use it for advertising.

## Retention and security

Queued messages are removed after processing. A title awaiting a photo expires after five minutes. The local state file retains up to 2,000 recent message identifiers for duplicate protection. Photos are not written to local disk by the bot. API credentials are stored in a local file excluded from version control. Asana may retain created tasks and attachments according to the account owner's settings and Asana's policies.

## Your choices and deletion requests

Only the configured sender number is processed; other senders are ignored. To request deletion of data held by the operator, email [octaviansasha@gmail.com](mailto:octaviansasha@gmail.com). Tasks and photo attachments already created in Asana must be deleted in Asana. WhatsApp chat history must be deleted in WhatsApp. Meta and Asana may retain records under their own policies.
